## Overview

DEMON-71 is a modern tactical and military surveillance web dashboard designed to showcase an advanced autonomous defense and monitoring system. The project presents a futuristic interface with immersive visuals and interactive sections for different operational modules.

### Key Features

- Bomb Defusal Module
- AI Surveillance System
- Mine Detection Unit with GPR-based active detection concept
- Network Jamming Module
- Environment Monitoring
- Security Protocols
- Futuristic UI with responsive layouts and animated visuals

---

## Project Modules

| Module | Description |
|---|---|
| Bomb Defusal | Simulates safe explosive handling and robotic analysis support. |
| AI Surveillance | Shows real-time object recognition and threat monitoring concepts. |
| Mine Detection Unit | Highlights GPR-based mine detection and HQ mapping capability. |
| Network Jamming | Demonstrates signal disruption and communication defense features. |
| Environment Monitoring | Displays sensing for gas, temperature, and environmental hazards. |
| Security Protocols | Covers secure data handling and mission safety systems. |

## Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/TarikurRahman/Team-DEMON71-Past
   ```

2. Navigate to the project folder:
   ```bash
   cd demon71
   ```

3. Open the project in your browser:
   - You can simply open `index.html` in a browser, or
   - Run a local server such as:
   ```bash
   python -m http.server 8000
   ```

4. Visit:
   ```text
   http://localhost:8000
   ```
